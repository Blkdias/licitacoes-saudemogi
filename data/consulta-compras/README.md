# Snapshot público da Consulta Compras

Estes arquivos são servidos pelo GitHub Pages e não consultam o Supabase no acesso público.

- `consultas.json`: array exportado de `consulta_compras`, incluindo `dados_detalhe`.
- `vinculos.json`: array exportado de `integracao_vinculos`.
- `manifest.json`: aponta para os arquivos publicados; atualize `generated_at` a cada exportação.

Enquanto os arrays estiverem vazios, a tela não consumirá saída do Supabase, mas também não exibirá registros oficiais. Não publique dados pessoais, credenciais ou informações restritas.
